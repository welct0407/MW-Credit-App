# Release record templates

Use [promotion-checklist.md](promotion-checklist.md) once per release. It is the single compact promotion record, not an additional enterprise gate. Reuse existing evidence and record applicable checks only.

The owning PWA/SQL delivery runner supplies its required machine-readable manifest; do not construct an AppSheet RC manifest or table-source mapping. Use [PWA delivery policy](../../../Documents/Rules/PWA_Orchestration.md) and [release workflow](../../../Documents/Rules/Release_Workflow.md).

[test-results.md](test-results.md) is optional for a batch whose evidence does not fit in the existing record. Small changes need no extra file.
