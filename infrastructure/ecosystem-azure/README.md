# R057 ecosystem adoption: azure (retired)

Retired on 8 November 2026 with the deletion of the Azure VM-01 workstation ([change note](../../Change%20Logs/CHANGE_NOTES_VM01_RETIREMENT_2026-11-08.md)). This root owned VM-01's OS disk, NIC, public IP, NSG, VNet `vnet-mwcredit`, data collection rule, two VM extensions and the backup protected item. The configuration now declares no resources; Git history holds the former configuration and import blocks.

Retirement steps: the backup protected item was destroyed (protection stopped, VM-01 backup data deleted; the shared vault `vm-backup-vault` and its EnhancedPolicy stay, because VM02 uses them). Azure refuses extension changes on a deallocated VM, so the two extensions were removed from state and deleted with the VM. The remaining six resources (disk, NIC, public IP, NSG, VNet, data collection rule) are destroyed by an ordinary refreshed plan of this empty configuration, which must show exactly `0 to add, 0 to change, 6 to destroy`; see the change note for status. Run it from a cloud session with `scripts/azure-cloud-session.sh terraform -chdir=infrastructure/ecosystem-azure plan -out=<private plan>` and apply that saved plan.
