## Live audit evidence and issues

1. `Payments[Eligible Charges]`: Single Full, Single Partial and First-day Auto target one specified charge without a due-date cutoff. Receive All and Lump Sum use Charge Date <= Payment Date; Loan Close includes all outstanding charges of the target loan. `Eligible Outstanding` sums that population. Amount Received validation enforces positive whole baht, not more than eligible outstanding; full methods require exact equality. These date scopes are intentionally retained.
2. `Charges[Payment - Snapshot Charge]` repeats the same method/date scope, validates nonnegative principal and interest balances, checks one processing receipt, prevents duplicate charge snapshots and freezes no new snapshots after allocation starts. Retain these safeguards.
3. Full-payment wrapper routes to `Common - Create Full Payment from Charge`: amount remaining, TODAY payment date, exact charge, Single Full. Partial routes to Payments_Form with exact target and Single Partial. Full wrapper blocks another Processing/Error borrower receipt.
4. `Payment - Reconcile` compares allocation/repayment sums, positive allocation count, unique allocation links, exact components/charge ownership and coverage. A static future charge alone is not a posting error. Changing charge populations during an in-flight receipt can cause a deliberate reconciliation Error; do not import during Processing/Error receipts.
5. Daily generation action, bulk selector and scheduled event currently do not require positive Current Daily Interest. Zero-rate loans can be selected for a zero/zero charge attempt. Scheduled event is daily 00:05, GMT+07, Loans; step is Generate Today's Charge. Add guards consistently, preserving other loan types.
6. Loans Last Interest Charge Date currently MAX of every related Charge Date; Accrued Interest Days subtracts that from TODAY without a zero floor. Future schedules can create negative accrual. Correct the date scope and nonnegative day count.
7. Borrowers Todays Collection Charges includes unpaid through today, or fully paid today. Future partial prepayments are excluded, so today's collections can be understated. Preserve due population while also showing actual payments dated today.
8. Statistics Pending Payment Amount currently SUM of all remaining charges, including future. Reconcile the operational due KPI to due-through-today charges.
9. Set Loan Closed currently checks only Outstanding Principal <= 0. It can close with unpaid interest; include remaining-charge balance protection.
10. OLAP Calendar Projected Interest directly extrapolates Current Daily Interest. Zeroing the existing value stops that extrapolation, but explicit fixed schedule interest/principal also needs forecast treatment. Existing Expected Interest This Month for a daily-interest loan has no explicit future manual-charge branch. Monthly pending-interest totals and borrower profit projections need date-scope reconciliation before loading October charges.
11. The target borrower's live balance is eight active loans totaling 31,000 principal and 24 collection charges totaling 8,700 remaining. The collection includes today's charges. The user's agreed 46,000 remains the authoritative replacement total; do not add a further day's interest on top.
