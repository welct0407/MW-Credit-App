# SDLC tooling verification — synthetic data only

These artifacts test local release helpers. They are not evidence of DEV/PROD app state, R005 readiness, production approval or deployment.

- `delta-tests.txt`: eight Node test cases, including command-line success/failure behavior.
- `dictionary-tests.json`: twelve passing synthetic dictionary assertions.
- `synthetic-delta.json`, `synthetic-input.xlsx`, `synthetic-before.png`: test input and inspected layout.
- `patched/dictionary.xlsx`, before/after PNGs, `error-scan.jsonl`, `verification.json`: candidate output, no detected formula errors and successful all-sheet value/formula roundtrip. Source bytes and unrelated row/formula preservation are checked separately by the integration test.
- `verification-summary.json`: scoped documentation/link checks and AGENTS word counts.

The fixtures use R000 purely as an example; no release number was reserved. Test scripts under `scripts/releases/` can reproduce them in a new output directory. XLSX inspect sidecars are generated by the bundled spreadsheet runtime.
