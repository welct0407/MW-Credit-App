# Borrower Detail compact category — R050

Published 29 September 2026 to Metabase dashboard3, tab105 **8 · Borrower Detail**. R050 remains Open. This is a report-only change; no AppSheet, database, model formula, access or notification change.

The top row retains Current principal, Active loans, Overdue and Portfolio share, now at widths 5/4/5/4. The fifth, width6 card is **BCG category** (question378). It reads the current governed quadrant from `reporting_borrower_matrix_v3` by selected immutable borrower ID, using the same category source as the former Current health table. It displays a compact symbol plus the exact category label: 🐄 Cash Cow, 🐕 Dog, ⭐ Star or ❓ Question Mark. Borrowers outside the active matrix cohort display `Outside active cohort`; no borrower selection returns no result. The category ignores the Detail activity-date filter. A full 2×2 plot was unsuitable within this metric row, so the symbol and label give a readable cue without hiding the category's meaning.

The wide **Current health · governed rolling window** placement for saved question295 was removed from Detail only; question295 remains saved and other pages were untouched. Later Detail rows moved up seven dashboard grid rows. The dashboard remains at 12 tabs and 272 placements. The seven charge-day lights (question369) keep their individual date labels and have no visible axis name. Metabase's scatter renderer displayed the default `Charge day` name with `title_enabled=false`; an explicit nonbreaking-space title visually suppresses it while preserving the ordinal labels and tooltip.
