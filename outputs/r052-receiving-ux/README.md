# Compact receiving UX

Delivery candidate f937bff is locally verified; exact-source full CI and DEV activation are pending. See [the single batch](batch.md) and [independent checks](independent-verification.md).

The Collection charge header opens one compact selection list. Its header shows the selected total, master selection and receive icon. The master selection covers all eligible due charges across pages; a future charge uses the existing single-full rule. Footer arrows provide paging. Select the existing Bank Transfer, Cash or Net-off at Disbursement method; the existing accounting effects still apply. Fresh online validation is mandatory before confirmation. All loading uses the same orange header indicator.

Drafts save quietly on this device; there are no extra Save/Discard action rows. A successful recorded payment returns to Collection and refreshes its context; history retains original/current details. An uncertain result retains recovery instead of pretending success. Navigation, autosave and reconnect never automatically post.

This batch adds no live financial test or notification. Owner hands-on acceptance remains separate; notifications remain Phase 8 and PROD is unchanged.
