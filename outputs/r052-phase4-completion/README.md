# DEV receiving hands-on

Open https://dev-lm.mw-credit.com and sign in with the pinned owner account. In Collection, open a borrower and choose Single Full, Receive all or individual charges. Receive all selects eligible charges across pages; it does not submit. Review fresh online amounts, receiving account, date, method, Notes and receipt, then Confirm. The result shows the original committed command separately from current payment data, allocations, repayments and cash movement. History supports governed Notes/manual receipt edits.

PNG and JPEG receipts are supported (5 MiB / 20 megapixels); HEIC is not supported. Already-viewed owner records and unsent drafts can remain on this device for up to 24 hours. Offline data is stale; financial review/posting requires reconnect and fresh validation. Reconnect never automatically posts. For an uncertain result use Check status and the retained command; do not create a duplicate payment.

This is ordinary DEV data for owner testing. Payments persist and require governed financial correction, not deletion. Agent proof used only a dedicated synthetic 2-baht fixture, now paid/closed with account net zero. Notifications remain Phase 8. Owner hands-on acceptance and production authorization are separate.
